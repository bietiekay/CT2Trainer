Steady-state tick / verification / value-read path, 0.41 vs 0.52.3
==================================================================
The field crash happens while the trainer sits read-only-idle 48-68 s
after restore, i.e. inside the steady-state poll loop.  The replay
(diff-summary.txt) covers attach + restore traffic; this artifact
covers the tick-loop code itself.

Extracted methods: poll, _check_patches, read_value, _value,
_value_read, _lua_tick*, _rearm_tick, _run_rearm.

Finding: the only behavioral difference is the 0.43 TGC
transient-read-skip handling in _check_patches (a read-side error
path: transient Win32 read failures skip the verification tick,
bounded by VERIFY_SKIP_STREAK_LIMIT=30, fail-closed) and the
matching streak reset in poll() on attach.  No write, allocation,
scan, protect or release behavior differs in the steady-state
path.
